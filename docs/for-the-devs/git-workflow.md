# Git & Conventional Commits

This project enforces Conventional Commits for clear, maintainable version histories.

## Conventional Commit Types
- `feat`: New documentation section, page, or feature.
- `fix`: Fixing broken link, typo, or layout bug.
- `docs`: Documentation improvement.
- `style`: Theme, CSS, or formatting adjustment.
- `ci`: GitHub Actions pipeline update.
- `build`: Zensical version upgrade or config change.

## Examples
```bash
git commit -m "feat: add model training architecture page"
git commit -m "fix: resolve broken internal navigation link"
git commit -m "style: adjust landing page badge layout"
```
