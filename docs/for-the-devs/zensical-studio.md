# Zensical Studio

Zensical Studio provides workspace-aware authoring assistance for Zensical projects.

## Capabilities
- Navigation assistance and structural checking.
- Internal link completion and validation.
- Live workspace diagnostics and error highlighting.

## Launching Studio
To open Zensical Studio within your project workspace:
```bash
zensical studio
```
*(Note: Availability depends on the local Zensical Studio installation).*
