# Badges

Badges are used on the landing page to provide quick visual metadata regarding build status, frameworks, and technologies.

## Standard Badge Syntax (Shields.io)
```markdown
![Python](https://img.shields.io/badge/Python-3.12-3776AB?style=for-the-badge&logo=python&logoColor=white)
```

## Guidelines
- Do not create fake badges.
- Keep badge style consistent across sections (`style=for-the-badge`).
- Group badges logically into Project, AI/ML, Infrastructure, and Deployment.
