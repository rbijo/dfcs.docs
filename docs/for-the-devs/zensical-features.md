# Zensical Features

Zensical natively supports a rich feature set for modern technical sites:

## Enabled Capabilities
- **Instant Search:** Fast client-side search indexed during build time.
- **Navigation Tabs:** Top-level navigation bar for major site sections.
- **Code Syntax Highlighting:** Pygments-powered syntax highlighting for Python, Bash, TOML, JSON, and SQL.
- **Mermaid.js Diagrams:** Native flowchart and sequence diagram rendering.
- **Icon System:** Integrated Material and FontAwesome navigation icons.
- **Responsive Layout:** Dynamic grid adaptation for mobile and desktop screens.
