# Domain FAQ Support Chatbot Documentation Framework

This repository contains the visual technical documentation website framework for **Domain FAQ Support Chatbot Using Fine Tuned Small Language Models**.

Built using **Zensical** static site generator and deployed via **GitHub Pages**.

## Local Development Setup

1. **Install Zensical:**
   ```bash
   pip install zensical
   ```

2. **Generate References:**
   ```bash
   python scripts/generate_references.py
   ```

3. **Serve Locally:**
   ```bash
   zensical serve
   ```

4. **Build Production Site:**
   ```bash
   zensical build --strict
   ```
